# 选手开卡网页

独立静态网页，运行时不依赖原项目、服务器接口、第三方库或网络资源。

## 使用与上传

双击 `index.html` 可以本地使用。上传以下五个文件到静态网站的同一个目录，以 `index.html` 为入口；文件名和相对路径保持不变：

- index.html：页面。
- style.css：桌面和手机样式。
- data.js：固定开卡参数、位置贡献系数与十队资料。
- model.js：开卡与个人贡献计算。
- app.js：配点、位置选择与队伍展示。

根目录的 `character-creator.zip` 仅包含这五个运行文件，解压后即可上传。README.md、check.cjs和原项目其他目录无需上传。

## 功能

- 80点开卡预算，枪法、反应、辅助、狙击和战术单项上限25，默认各16点。
- 滑块和数字输入同步，超过单项或剩余预算时限制到允许值；支持平均分配与清空。
- 实时显示七维与所选位置的个人战力贡献，七维旁标注完整英文名称。七维保留两位小数，个人贡献显示四位小数，不提前取整；全队仍按五人完整贡献合并后向下取整。
- 位置只改变个人战力贡献，不改变已有七维。
- 十支队伍为只读参考，展示整数队伍战力、五人阵容、位置和个人贡献。队伍小卡片只显示队名与战力；选手贡献与展开的原始七维表均按个人战力贡献从高到低排列。选手条形按同队最大个人贡献统一缩放，颜色表示七维来源，逐项贡献数值直接显示。原始七维可展开查看。
- 页面不展示公式、参数编辑、单点收益、培养、骰子或胜率。无保存与联网提交；刷新后恢复默认开卡。

## 数据同步与检查

在项目根目录运行 `python hltv/modeling/integer_baseline.py`，自动同步本页的 `data.js`，使用正式默认规则与Excel位置。调参台浏览器中的临时方案不会影响本页。

运行 `node character-creator/check.cjs` 核对开卡、位置贡献和职业选手数据。发布压缩包是打包时的文件副本；后续更新页面或数据后需重新打包。
